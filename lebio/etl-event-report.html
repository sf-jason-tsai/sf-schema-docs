新增自訂欄位

本批依 CRM資料表關聯說明文件.docx 事件關聯規範,將舊系統的 事件列表.xlsx(29,854 筆)遷入 lifenergy 正式 org 的標準物件 Event(SF UI 顯示為「行事曆／事件」)。全部成功寫入,0 失敗。所有紀錄標記 mark__c = 'sf'。

原生優先:事件的核心欄位(主題、起訖時間、全天旗標、說明、聯絡對象、相關客戶)全部對應到 Event 標準欄位,無需自訂;僅將舊系統特有的補充資訊(原始負責人、來源客戶名稱、原始建立時間…)存入 6 個 Legacy_* 自訂欄位保留可回溯性。
時區正確:台灣為 UTC+08:00,匯入時將每筆事件的台灣「牆上時間」正確換算為 UTC 儲存(startUTCms = 午夜UTC + (時*60+分 − 480)*60000),確保在 SF 行事曆顯示的時間與原系統一致,不偏移 8 小時。

3關聯解析(WhoId / WhatId)

依 docx 事件關聯規範,事件同時可掛「聯絡人/潛在客戶」與「客戶」。解析邏輯:

  • WhoId:來源為 003… → 對映既有 Contact;00Q… → 對映既有 Lead;佔位碼/空白則留空。
  • WhatId:優先取 WhatId(001…) → Account;否則以 AccountId 對映;皆無則留空。

4資料清洗

  • 所有文字欄位 trim 前後空白(含全形 U+3000)、收合連續空白、移除不可見控制字元。
  • 時間:台灣牆上時間正確換算為 UTC 儲存;時長由起訖時間差計算。
  • 主題空值以「(無主題)」補入(66 筆),避免行事曆空白。
  • 全天事件(4 筆)改用 ActivityDate + IsAllDayEvent=true,避免時間軸錯位。
  • 去重原則:僅完全相同的列才去重;舊 Id 重複組 = 0。
