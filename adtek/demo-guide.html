行銷 ROI

Energy Taiwan 智慧能源週、台北自動化展、工廠節能補助 EDM、通路夥伴聯合行銷、中東能源展（杜拜）—— 5 檔真實展會用 原生 Campaign 記錄預算 / 實際花費 / 預期營收。34 位展會潛客（Lead）以 CampaignMember 掛回各活動、商機再掛回 Campaign，形成「潛客 → 成員 → 商機 → 成交金額」完整回推鏈。

紛享銷客：Campaign 成效無法量化，行銷投入是黑箱；不知哪場展會、哪個管道帶來的客戶真的成交，預算分配全憑感覺。

✓ 潛客進 CRM 即掛 Campaign，串接商機成交金額回推各活動 ROI；行銷 ROI 戰情室 Dashboard 一頁看完「投入 vs 成交、管道別成交、潛客漏斗」，預算分配有數據依據。

客戶管理（公海 / 分級 / 商機）

60 家終端客戶 + 15 家通路統包商，A/B/C 三級分類（分級欄位 Tier 已上記錄頁「帳戶資訊」，與年營收 / 行業別並列，佐證分級邏輯）；超過 90 天未拜訪自動落入 公海客戶池（21 家），業務可一鍵認領。客戶資料採台灣真實企業公開資訊（官網 / 縣市 / 規模級距 / 總機），非空殼假資料。集團母子結構：台積電（6 廠）、群創（3 廠）、友達（2 廠）各有總公司節點，記錄頁可從母公司下鑽子廠。

紛享銷客：公海規則靠人管，客戶「躺著」沒人追。

✓ 公海：排程 Flow 每日自動釋出（RT=終端客戶 且 未拜訪≥90天 → 收歸公海管理者）+ Screen Flow 一鍵認領（改 Owner + 天數歸零）。分級：A/B/C 為制度規則落地的欄位值（依營收 / 規模判定），頁面與年營收並列佐證，非即時自動重算。

業績預測（Forecast Table + 原生協同預測）

把客戶月報 PPT 的 Forecast 表格形態做成戰情室首頁主視覺 「銷售預測看板」：逐月目標／實際／累計/達標率/缺口一列一月，目標值取自新建原生協同預測配額 ForecastingQuota（掛主管 × 12 月 × 商機金額型別，加總 1.3 億），與導覽列原生「預測」Tab 同一份配額 = 單一真相；下接階段漏斗轉換率。

現況：無 pipeline forecast、達標與否只能靠感覺；缺口與各階段轉換率只能口頭問業務，無法提前預警。

✓ 戰情室即時顯示逐月達標率與缺口，8 月起累計跌破 100% 自動跳落後預警，年度缺口 4,140 萬、pipeline 覆蓋 1.06 倍一眼看到；階段轉換率低於基準自動標紅供輔導。實際值即時算自 CRM，數字全連動、零手工。

售後服務與派工

20 張售服工單，透過 Flow 自動開 WorkOrder 並產生 ServiceAppointment，指派工程師團隊 —— 可上 Dispatcher 甘特圖排程。工程師處理時右側 Knowledge 即搜即用（19 篇自家維修知識）。

現況：銓盛開單 / 派工目前靠 email 往返，沒有統一的案件狀態與排程視圖，主管無法即時看到「誰在處理、處理到哪」。

✓ Field Service 派工鏈：Case → 工單 → 派工 → 工程師，全程狀態透明、可排程、可查知識庫。

內部溝通（第 5 主題）· Slack Swarm 協作已就位（商機 + 售服案）

對應客戶三個角色的溝通需求：業務（隨手查客戶 / 商機、討論案子）、業助（協助業務 / 售服 / 財務跨部門溝通）、工廠（庫存 / 出貨公告）。銓盛-Adtek App 內的商機與售服案記錄頁都已內建官方 Slack Swarm 群集協作元件（Salesforce 原生 runtime_service_swarming；Swarm.RelatedRecordId 原生支援 Opportunity / Case 等物件）。沿用此 CBUSDO org 既有的 Salesforce ↔ Slack 連線（THERMOS demo 2026-07-15 已完成工作區連線 = Slack Demo 35769）。這是 App 層級覆寫，其他 App 開同一筆記錄完全不受影響。

現況：討論在 LINE / 群組、資料在系統，兩邊對不上；跨部門溝通靠人轉述。

✓ 記錄頁直接發起 Swarm 頻道討論，對話與商機 / 案件綁在同一畫面並同步到 Slack，業助可把業務 / 售服 / 財務拉進同一頻道協作。

org↔Slack 連線狀態：此 org 已連過 Slack 工作區（THERMOS 那次接好，#service-swarm-thermo 頻道 + incoming-webhook 測試成功可證）。商機頁的 Swarm 元件本來就正確、可運作，非語意錯誤。
「此處仍空無一物 / 找不到群集頻道」的真正原因：那只是該筆商機尚未有人發起 Swarm（全 org 目前 Swarm 記錄 = 0，屬「還沒建立」而非「壞掉」）。現場動作：開該商機 → Slack 分頁 → 按 建立 / 發起 Swarm（Create Swarm） → 頻道即出現在此並同步至 Slack。首次於新工作區操作時，若跳授權畫面，用 SE / 客戶 Slack 帳號確認一次即可。
誠實範圍說明：org 內已備妥「記錄頁 → Swarm 協作分頁 + 通知推送」且連線就緒，現場發起 Swarm 即有頻道。至於「在 Slack 裡用 slash 指令主動查詢 CBUSDO 客戶 / 商機資訊的查詢型 bot」，屬 Slack 工作區端能力，需在 Slack 端額外安裝設定 Salesforce Sales / Service for Slack app，不在本次 org 內交付範圍；可作為後續延伸項目。
