5Outlook Integration · Salesforce Inbox 設定

讓業務在 Outlook 或 Gmail 直接看/建 Salesforce 資料。三大功能：

📨 Outlook Integration
Side Panel

Outlook 右側面板顯示信件發信人對應的 Salesforce Contact / Account / Opp，可直接建 Task。

🤖 Einstein Activity Capture
EAC (免費 Basic 版)

自動 sync Email + Calendar Event 到相關 Salesforce record，客服/業務不用手動 log activity。

📧 Email-to-Salesforce
BCC alias

寄信 BCC 到你專屬的 emailtosalesforce alias，Salesforce 自動記為 EmailMessage 綁 Contact。

Setup 步驟

  1. 啟用 Outlook Integration：設定（Setup）→ Outlook 整合與同步（Outlook Integration and Sync） → Enable → 讓所有 user 可用
  2. User 端裝 add-in：Outlook 桌面版 → 取得增益集（Get Add-ins） → 搜尋「Salesforce」→ Install。網頁版 Outlook 也支援。
  3. 啟用 EAC：設定（Setup）→ Einstein 活動擷取（Einstein Activity Capture）→ 設定（Configurations） → 新增組態（New Config） → 選 users → 設 sync 方向（Both/Salesforce-only）
  4. Email-to-Salesforce：設定（Setup）→ 電子郵件至 Salesforce（Email-to-Salesforce）→ Enable → 每位 user 有專屬 email alias（例：emailtosalesforce@abc123.mysalesforce.com）
  5. Salesforce Inbox（更進階）：需要額外 Sales Cloud Einstein 或 Inbox licence · 設定（Setup）→ Salesforce Inbox
💡 CBUSDO 是 SDO org，Outlook Integration 已內建可用，只要 user 端裝 add-in 就能開始 demo

6Sales Path · 3 個 Opp RT 各配一條 Path

為 3 個銀樺 Opp RT 各配一條 Path，讓業務有可視化 stage 進度。

設定（Setup）→ 路徑設定（Path Settings） → 新增路徑（New Path）

  1. Path 1 · 銀樺 · 新品上架 Path
    Object = Opportunity, 記錄類型（Record Type）= SBH_Product_Listing, 下拉選單（Picklist）= 階段（StageName）
  2. 7 個 stage 各填「關鍵欄位」+「AE 指引」：
    Prospecting
    →
    Qualification
    →
    Needs Analysis
    →
    Proposal/Price Quote
    →
    Negotiation/Review
    →
    Closed Won
  3. 對 SBH_Seasonal_Deal 和 SBH_Renewal 重複同樣步驟
  4. 啟用（Activate）→ 到商機（Opp）記錄頁 就會看到頂端 Path bar

建議每 Stage 的 Key Fields + Guidance

Stage關鍵欄位提示（Key Fields to prompt）AE 指引
ProspectingSBH_Slot_Fee__c · Description初步接觸，準備樣品清單
QualificationAmount · CloseDate確認客戶預算 + 承諾量
Needs AnalysisAmount · SBH_Slot_Fee__c了解通路要求、上架費結構
Proposal/Price QuoteSBH_Slot_Fee__c · Amount正式提交 Quote，選對應 Pricebook

8Demo Script · 5 分鐘走完 pipeline

  1. 從 Lead 開始（30 秒）— 打開「銀樺國際 Sales」App → Leads tab → 選「Salon de Vin 侍酒沙龍」→ 展示 Lead 詳細（LeadSource=Referral 星坊介紹）→ 點「Convert」→ 產出 Account + Contact + Opp。
  2. Account Hierarchy（30 秒）— 打開「SOGO 太平洋崇光百貨」→ 展示右側 Account Hierarchy → SOGO Corp 底下有忠孝館 + 復興館 → 點分店看 ParentId。
  3. Opp Kanban（1 分鐘）— Opportunities tab → 切 Kanban view → 拖 opp 從 Proposal → Negotiation → 講「業務就這樣移動 pipeline」。點 opp 進 detail → 展示 Sales Path bar + OpportunityContactRole。
  4. Multi-Pricebook Quote（1 分鐘）— 選一個 Opp（例：MAISON HÉLIA 進微風信義）→ Quote related list → 展示 Quote 使用「銀樺國際 · 百貨通路 Pricebook」→ QuoteLineItem 顯示 75% 通路價。點「Create PDF」→ 標準功能。
  5. Order Activation（30 秒）— 從 Opp → Order → 展示 Draft → 點「Activate」→ Status 變 Activated → 講「Order 走完就 revenue recognition」。
  6. Campaign Hierarchy（45 秒）— Campaigns tab → 打開「2026 春夏檔期」→ 底下有 KLIMA 品鑑會 + 微風快閃活動 → Campaign Members 有百貨採購都被邀請。
  7. Reports/Dashboard（30 秒）— Reports → Standard 「Opportunity Pipeline」→ 看 15 個 SBH_ opp 分 Stage 統計 → 講「已有真實資料可玩 report」。
  8. 收合 · 定價 story（30 秒）— 「你們現在用 Excel 管 SOGO 上架資料 · Salesforce 上這 20 個 Account × 15 個 Opp 就是每天業務工作的核心 · Sales Cloud licence NT$ 4,500/user/月 起 · 8 個業務 = NT$ 36K/月」
