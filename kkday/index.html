3Experience Cloud · 完整建站步驟（LWR + Guest User）

核心 LWC 已 deployed：kkdayHome ── 一支元件含 Hero banner、Search bar、8 個 category card grid、熱門商品 grid、Trust bar。可放 Lightning Home page（測試）或 Experience Site 頁面。

Step-by-Step · UI 建立 LWR Experience Site

  1. 啟用 Digital Experiences：設定 → 快速搜尋輸入「數位體驗」→ 設定 → 勾「啟用數位體驗」→ 網域自訂 kkday-demo（會產出 https://cbusdo--kkday-demo.sandbox.my.site.com）
  2. New Site：設定 → 全部網站 → 新網站 → 選 Build Your Own (LWR) template → 名稱 KKDAY Travel → URL kkday
  3. 套用 Branding：Experience Builder → 主題（Theme）→ Colors：主色 #FE5C63（coral）、輔色 #FF8A65（warm）、背景 #FAFAFA、字型 PingFang TC / Salesforce Sans
  4. 編輯 Home Page：Home → 拖入 Custom Component → kkdayHome（唯一的元件就搞定所有 hero/search/category/product 展示）
  5. Guest User FLS：設定 → 全部網站 → KKDAY Travel → 建置器 → 設定齒輪 → 一般 → Guest User Profile → Object Settings 開 Product2 (Read) 並勾所有 KKD_* 欄位
  6. Public Access：管理員 → 網站設定 → 勾「允許不含登入使用者存取本網站」+ 「允許不用登入的自我註冊」
  7. Guest 對 Product2 分享：Sharing Settings → Product2 → Guest User Access → Read Only
  8. Publish：Experience Builder 右上角「發佈」→ 30-60 秒生效
  9. 訪問你的網站：https://cbusdo--kkday-demo.sandbox.my.site.com/kkday
